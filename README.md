# Health Awareness App

## About the Project
Health Awareness is an Android application designed to promote healthy lifestyles and improve health awareness.

## Features
- User Login and Registration
- Daily Health Tips
- Health Awareness Information 
- Water Drinking Reminders
- Exercise Reminders
- Medicine Reminders
- Health Progress Calculation

## Technologies Used
- Java
- XML
- Android Studio

## Purpose
The main purpose of this application is to encourage people to follow healthy habits and stay aware of their health.
